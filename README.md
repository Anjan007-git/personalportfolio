# Anjan Prajapati — Personal Portfolio

The personal portfolio of **Anjan Prajapati** — AI engineer and full-stack developer based in Mumbai, India.

Featuring:
- Interactive macOS desktop simulation with draggables, windows, dock, and terminal
- Responsive layouts with customized typography, shaders, and animations
- Next.js dynamic chunk loading, RSC payload streaming, and Next.js Image Optimization
- Working contact form submission with server action processing
- 100% desktop, tablet, and mobile responsiveness

---

## 🚀 Quick Start

Run the portfolio locally with **Node.js** or **Python** (**zero external dependencies** required):

### Option 1: Node.js (Recommended)

```bash
# Start server on http://localhost:3000
npm start
# or: node server.js
```

---

### Option 2: Python

```bash
# Start server with Python on http://localhost:3000
python server.py
# or: npm run py
```

## 📱 Routes & Features

- `/` (Home) — Hero section, interactive desktop simulation, project highlights, timeline, contact CTA

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router, RSC)
- **Styling**: Tailwind CSS, PostCSS, custom CSS variables
- **Interactive UI**: Framer Motion, GSAP, Canvas / WebGL shaders
- **Runtime**: Node.js / Python static server with full Next.js optimizer emulation
